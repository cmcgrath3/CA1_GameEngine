# CA1_GameEngine

### CA 1 for 2D Game Engine Development - 2D Game in Unity

Background Music was sourced from GWriterStudio and sound effects were sourced from cabled_mess on the Unity Assets Store. All other assets featured in the game were created by myself.  

Code for the game was referenced from scripts written in class. The unseen mechanics were based on modifications of the code we were taught.
